# Socials Website

This is the source code of the website used in:
[https://socials.dusko.boo](https://socials.dusko.boo)

# Why is it here?
This project is on GitHub, due to it being easier for me to manage updates on my servers (via CD), and for anyone who likes my about me site, to look at the source code, and clone it/make something similar

# Why is the pfp "hard" to save on the website?
The pfp icon on the site is purposefully harder to save, to protect the artist's ([milkshauxx](https://toyhou.se/Milkshauxx))'s work. Yes I know you can easily download it using developer tools, or just by going to my CDN, but still...
